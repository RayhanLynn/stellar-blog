本站是静态个人博客，不提供用户账户，也不主动收集姓名、邮箱等个人资料。

为了显示访问量，本站使用不蒜子统计服务记录页面访问次数和独立访客数。评论功能启用后将使用 GitHub Discussions 与 Giscus，留言数据由 GitHub 保存，并受 GitHub 隐私政策约束。

外部图片、字体或链接可能由对应服务提供方处理访问请求。本站字体文件和公式字体均随网站本地部署。

本说明会随站点功能调整而更新。
