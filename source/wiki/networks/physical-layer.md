## 比特与信号

计算机处理的 0 和 1 需要通过具体的物理信号传递。铜线上的电压变化、光纤中的光脉冲、无线空间中的电磁波，都可以承载信息。

物理层关心的是如何让接收端识别这些变化。它不需要理解网页内容，也不负责判断应用请求是否成功。

## 速率和带宽

在日常语境中，带宽经常用来描述每秒能够传送的比特数。但讨论信号时，带宽也有频率范围的含义，要注意上下文和单位。

| 指标 | 常用单位 | 含义 |
| --- | --- | --- |
| 数据速率 | bit/s | 单位时间传送的数据量 |
| 时延 | ms | 信息到达所需时间 |
| 频率带宽 | Hz | 信号占用的频率范围 |

## 发送时延与传播时延

发送时延可以用数据长度除以发送速率计算。传播时延则由距离和信号传播速度决定。

设数据长度为 $L$，发送速率为 $R$，则发送时延为 $t_{\mathrm{tx}} = \frac{L}{R}$。

$$
t_{\mathrm{total}} = t_{\mathrm{proc}} + t_{\mathrm{queue}} + \frac{L}{R} + \frac{d}{v}
$$

其中 $d$ 为传播距离，$v$ 为信号传播速度。

### 有噪声信道的容量

香农公式给出了理想编码条件下有噪声信道的容量上限：

$$
C = B \log_2\left(1 + \frac{S}{N}\right)
$$

$B$ 为带宽（Hz），$S/N$ 为线性信噪比。若给出的是分贝，需要先换算，不能直接代入。

```python
def transmission_delay(bits, rate):
    if rate <= 0:
        raise ValueError("rate must be positive")
    return bits / rate

print(transmission_delay(1_000_000, 10_000_000))
```

> 带宽像道路的宽度，传播时延更接近两地之间的距离。拓宽道路，不会让两个城市自动靠近。

## 编码的意义

编码需要兼顾可识别性、同步和信道特性。接收端除了读出电平，还需要知道每一个符号从哪里开始、在哪里结束。
